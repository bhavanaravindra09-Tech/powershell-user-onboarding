# Support Knowledge Base

A clean, searchable, single-page knowledge base with 8 step-by-step
support articles — the kind of self-service portal every help desk
wishes it had.

## Why this exists

Good documentation deflects tickets and makes every support agent
faster. This project shows technical writing: turning messy
troubleshooting knowledge into articles a non-technical user can follow.

## Articles included

1. Reset a user password (Active Directory)
2. VPN won't connect
3. Printer shows offline
4. Outlook crashes or won't open
5. Wi-Fi connected but no internet
6. Computer is very slow
7. Set up multi-factor authentication (MFA)
8. What to do with a phishing email

## View it

Open `index.html` in any browser — no server or build step needed.
Use the search box to filter articles by keyword.

## Files

- `index.html` — the whole site: content, styling, and search in one file
